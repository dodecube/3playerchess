# ♞ Шахматы на троих — «Три полудоски» (Three Half Chess)

Вебсайт для игры в [Three Half Chess](https://greenchess.net/rules.php?v=three-half) с друзьями:
онлайн-комнаты по ссылке (3 игрока + зрители, чат) и режим за одним экраном.

![игроки](https://img.shields.io/badge/игроки-3-red) — ⚪ Белые → 🔴 Красные → ⚫ Чёрные, каждый против всех.

## Быстрый старт

```bash
npm install
npm start        # http://localhost:3000  (порт задаётся переменной PORT)
npm test         # тесты движка правил + интеграционный тест комнат
```

Создайте комнату → отправьте друзьям ссылку вида `/?room=ABC12` → займите места → «Начать партию».
Комнаты живут в памяти сервера (без базы данных) — рестарт сервера их сбрасывает.

## Как устроена партия

- **Доска** — три половинки 8×4. Любые две, состыкованные по средней линии (верхняя
  повёрнута на 180°), образуют доску 8×8. Ход допустим, если он допустим на любой из
  двух досок, содержащих половинку с фигурой. Поэтому прямая линия через «шов»
  продолжается в **зеркальной вертикали** (a↔h, b↔g и т. д.). На сайте собранная пара
  половинок показана как обычная доска, третья — полоской под ней; пару можно менять
  кнопками над доской, все ходы выбранной фигуры подсвечиваются на обеих частях экрана.
- **Пешки** идут от домашнего края своей половинки через центр в любую чужую
  половинку, там — к её домашнему краю, где превращаются. Двойной ход, взятие на
  проходе и рокировка — как в обычных шахматах (на своей половинке).
- **Шах**: нельзя оставлять своего короля под боем любого из двух соперников.
- **Конец партии** (по правилам Green Chess для троих): мат ходившему игроку — ему **0**,
  тому из шахующих, кто раньше по очередности мог бы взять короля, — **1**, третьему — **½**.
  Если ход третьего игрока открыл линию и король может быть взят до своего хода —
  партия заканчивается сразу («берущийся король»). Пат, соглашение всех троих,
  троекратное повторение, 50 кругов без движения пешки/взятия или одни короли — ничья ½–½–½.
  Сдача — в пользу указанного игрока и с согласия третьего.
- Свободное место (никого нет за цветом или игрок отключился) может ходить любой
  участник комнаты — удобно ждать друга или доигрывать партию.

Полные правила есть в панели «Правила (кратко)» прямо на странице партии.

## Структура проекта

| Файл | Что это |
|---|---|
| `public/engine.js` | Движок правил (UMD): один и тот же код работает на сервере (авторитетная проверка ходов) и в браузере (подсветка ходов, игра за одним экраном). Модель доски и нюансы правил описаны в шапке файла. |
| `server.js` | Express + Socket.IO: комнаты с кодом, места ⚪🔴⚫ и зрители, переподключение с сохранением места (по `clientKey` в localStorage), чат, голосования о ничьей/сдаче. |
| `public/index.html`, `public/style.css`, `public/client.js` | Одностраничный интерфейс без сборки. |
| `test/engine.test.js` | Правила: ходы через шов, пешки, рокировка, шах от третьего, мат и счёт, взятие на проходе, «берущийся король», фазз-тест случайных партий. |
| `test/server.test.js` | Интеграция: 3 сокет-клиента — создание комнаты, места, очерёдность ходов, отклонение нелегальных ходов, чат, ничья голосованием. |

## Заметки по реализации правил

Оригинал (Ralph Betza, ~1980) давал армии по ходу за каждую занятую полудоску и захват
армий при мате; здесь реализованы **правила Green Chess** (Uray M. János, 2013):
один ход за круг и окончание партии при первом мате со счётом 1–0–½.

Направление пешки задано без скрытого состояния: на своей половинке — от домашнего
края к центру, на чужой — к домашнему краю той половинки, где она превращается.
Взятие на проходе доступно только сразу следующим ходом, как в ФИДЕ.
